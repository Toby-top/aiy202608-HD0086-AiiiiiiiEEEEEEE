# DESIGN.md

## 气质与意象
- 关键词：温暖知性、从容自信、国际化
- 意象：秋日午后的常春藤图书馆，阳光透过落地窗洒在深色木质桌面上，一位温和但犀利的招生官与你进行一场关于梦想与成长的对话
- 不是冷冰冰的考试系统，而是一个有温度、有深度的对话伙伴

## 配色方案
- 主色：深墨绿 `#1a3a2a` - 常春藤叶的沉稳与生命力
- 辅助色：暖米白 `#f5f0e8` - 旧书页的温暖质感
- 点缀色：琥珀金 `#c9953c` - 图书馆铜质台灯的柔和光泽
- 文字色：深炭灰 `#2d2d2d`
- 次要文字：`#6b7280`
- 边框/分割线：`#e5e1d8`
- 错误/警告：`#b45309`
- 成功：`#166534`

## 字体排版
- 英文标题：Playfair Display（衬线体，优雅学术感）
- 英文正文：Inter（无衬线，清晰易读）
- 中文标题：思源宋体 Noto Serif SC
- 中文正文：思源黑体 Noto Sans SC
- 字号层级：页面标题 2.5rem，卡片标题 1.25rem，正文 1rem，辅助文字 0.875rem

## 动效与交互
- 缓动曲线：cubic-bezier(0.4, 0, 0.2, 1)
- 过渡时长：200ms-300ms
- 按钮悬停：微妙的背景色变化 + 轻微上移
- 对话气泡：淡入 + 轻微上滑

## 设计禁忌
- 不要使用科技蓝/紫蓝渐变
- 不要使用过度圆角（保持 8-12px）
- 不要使用霓虹色或高饱和色彩
- 不要使用卡通风格的图标
- 不要过度动画，保持从容克制
